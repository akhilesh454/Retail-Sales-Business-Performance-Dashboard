# Retail Sales & Business Performance Dashboard

An interactive retail analytics dashboard and business performance report developed during my Data Analytics training at **SpeedUp Infotech**.

## 📊 Project Overview

The project analyzes retail sales data to understand sales performance, products, customers, stores, regions, time-based trends, and returns.

## 📑 Dashboard Pages

- **Home** – Overall business performance
- **Overview** – Stores, Products & Region
- **Sales and Time** – Sales trends and time-based analysis
- **Product Performance** – Product-level performance
- **Customer Insights** – Customer behavior and sales insights
- **Store and Region** – Store and regional performance
- **Returns and Quality** – Returns and quality analysis

## 🛠️ Tools & Skills

- Power Query
- Pivot Tables
- Data Cleaning
- Data Analysis
- Dashboarding

## 📂 Dataset

The dataset used for this project was downloaded from **Kaggle**.

## 🎯 Objective

To transform raw retail data into an interactive dashboard that provides meaningful business insights and supports data-driven decision-making.
